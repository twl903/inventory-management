Request Data Flow

User Action User selects a filter in FilterBar.vue (period, location, category, status)
Shared State useFilters() composable updates a singleton ref, watched by all views simultaneously
API Call api.js builds URLSearchParams, skipping any "all" values, and fires an Axios GET
Backend Filter FastAPI runs apply_filters() and filter_by_month() over the in-memory JSON arrays
UI Update Response sets a ref; computed properties re-derive and Vue re-renders only changed DOM nodes
